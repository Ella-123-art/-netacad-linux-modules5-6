# NetAcad Linux Course — Modules 5 & 6

This repository documents my hands-on work for **Module 5: Command Line Skills** and **Module 6: Getting Help**, part of a NetAcad Linux course.

## Contents

- `NetAcad_Modules5-6_Writeup.md` — full writeup covering commands used, explanations, and key takeaways
- `images/` — terminal screenshots showing the hands-on lab work referenced in the writeup

## What's Covered

**Module 5 — Command Line Skills**
- Filesystem navigation (`ls`, `ls -l`)
- Command chaining and conditional execution (`;`, `&&`, `||`)
- Command history (`history`, `!n`, `$HISTSIZE`)
- Environment variables and command lookup (`$PATH`, `which`)
- Shell builtins vs. external commands (`type`, `alias`)

**Module 6 — Getting Help**
- System date and manual pages (`date`, `man`)
- Finding files and commands (`locate`, `whereis`)

## Environment

Ubuntu 18.04.5 LTS, lab environment with `sysadmin` user account.
